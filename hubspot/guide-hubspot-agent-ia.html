Créer la page Agent IA dans HubSpot

5 modules modifiables, puis une page en brouillon sur le modèle Flex du thème Flatchr (menu et footer du site inclus). Le rendu final est celui de la maquette validée.

Toi, dans le Gestionnaire de design

Étapes 1 à 4 ci-dessous. Tu crées chaque module en collant le code, tu ajoutes ses champs, puis tu montes la page.

Raccourci avec Damien

Depuis la branche claude/nifty-fermi-at6wdw du repo, une commande importe les 5 modules avec tous leurs champs et textes : hs upload hubspot/modules "Agent IA". Tu passes ensuite directement à l'étape 3.

1Ouvrir le Gestionnaire de design

  1. Dans HubSpot : Contenu → Outils de conception (Design Manager). Selon ton interface, il peut être sous Marketing → Fichiers et modèles.
  2. Crée un dossier Agent IA à la racine : Fichier → Nouveau dossier.

À savoir : les noms de menus peuvent varier légèrement selon la langue ou la version de HubSpot. Le principe reste le même.

2Créer les 5 modules

Pour chaque module : crée le fichier, colle le code, ajoute les champs, publie le module. Les champs n'ont pas besoin de valeur par défaut : les textes se saisissent à l'étape 3.

Le point qui fait tout marcher : le nom HubL de chaque champ doit être identique à celui du tableau, sinon le texte n'apparaît pas. Le menu « Ajouter un champ » demande un type (ex. tape « Texte »), puis tu renseignes le libellé et le nom HubL dans les réglages du champ.

Champs répétés : « Exemples de demandes » et « Points clés » sont de simples champs Texte avec l'option Répéter activée. Seuls 2 modules ont de vrais groupes (Démo WhatsApp : messages ; Cartes : cartes) : un groupe ne se crée pas depuis « Ajouter un champ », il se forme en regroupant des champs déjà créés.

// Champ de saisie : ouvre l'accès gratuit dans un nouvel onglet avec la demande en ?prompt=
document.querySelectorAll('.aia-hero').forEach(function (h) {
  var url = h.dataset.url, f = h.querySelector('[data-aia-form]'), t = f.querySelector('textarea');
  f.addEventListener('submit', function (e) {
    e.preventDefault();
    var q = t.value.trim();
    if (!q) { t.focus(); return; }
    window.open(url + (url.indexOf('?') < 0 ? '?' : '&') + 'prompt=' + encodeURIComponent(q), '_blank', 'noopener');
  });
  t.addEventListener('keydown', function (e) {
    if (e.key === 'Enter' && !e.shiftKey) { e.preventDefault(); f.requestSubmit(); }
  });
  h.querySelectorAll('.aia-chip').forEach(function (c) {
    c.addEventListener('click', function () { t.value = c.textContent; t.focus(); });
  });
});

document.querySelectorAll('.aia-video-sec .aia-video').forEach(function (box) {
  var url = (box.dataset.url || '').trim();

// Démo WhatsApp : conversation visible d'emblée, jouée en animation à l'arrivée à l'écran,
// puis rejouée automatiquement 10 minutes après la fin (dès que la démo est visible).
var AIA_REPLAY_MINUTES = 10;
document.querySelectorAll('.aia-demo').forEach(function (sec) {
  var chat = sec.querySelector('[data-aia-chat]'), msgs = [].slice.call(chat.querySelectorAll('.aia-msg')), timers = [];
  if (!msgs.length || window.matchMedia('(prefers-reduced-motion: reduce)').matches || !('IntersectionObserver' in window)) return;
  var visible = false, due = true, playing = false;
  function play() {
    due = false; playing = true;
    timers.forEach(clearTimeout); timers = [];
    msgs.forEach(function (m) { m.classList.add('aia-hidden'); m.classList.remove('aia-in'); });
    chat.scrollTop = 0;
    var delay = 400;
    msgs.forEach(function (m) {
      var isAgent = m.classList.contains('aia-agent');
      if (isAgent) {
        timers.push(setTimeout(function () {
          var t = document.createElement('div'); t.className = 'aia-typing'; t.innerHTML = '<i></i><i></i><i></i>';
          chat.appendChild(t); chat.scrollTop = chat.scrollHeight;
        }, delay));
        delay += 1100;
      }
      timers.push(setTimeout(function () {
        var t = chat.querySelector('.aia-typing'); if (t) t.remove();
        m.classList.remove('aia-hidden'); m.classList.add('aia-in');
        chat.scrollTop = chat.scrollHeight;
      }, delay));
      delay += isAgent ? 1600 : 1300;
    });
    // Fin de la démo : prochaine lecture dans 10 minutes
    timers.push(setTimeout(function () {
      playing = false;
      timers.push(setTimeout(function () { due = true; if (visible) play(); }, AIA_REPLAY_MINUTES * 60000));
    }, delay));
  }
  new IntersectionObserver(function (entries) {
    visible = entries[0].isIntersecting;
    if (visible && due && !playing) play();
  }, { threshold: 0.35 }).observe(chat);
});

// Compte à rebours jusqu'à la date de lancement (format 2027-01-01T00:00:00+01:00)
document.querySelectorAll('.aia-launch-sec .aia-countdown').forEach(function (cd) {
  var target = new Date(cd.dataset.date).getTime();
  if (isNaN(target)) { cd.hidden = true; return; }
  function tick() {
    var s = Math.max(0, Math.floor((target - Date.now()) / 1000));
    cd.querySelector('[data-d]').textContent = Math.floor(s / 86400);
    cd.querySelector('[data-h]').textContent = Math.floor(s % 86400 / 3600);
    cd.querySelector('[data-m]').textContent = Math.floor(s % 3600 / 60);
  }
  tick(); setInterval(tick, 30000);
});

10Faq two col (thème Flatchr) · FAQ, tout en bas

Module du thème « Faq two col » (celui de ta page /faq). Laisse les champs « Heading » et « Text » du module VIDES : sinon un 2e titre H1 apparaît. Une seule colonne dans « Faq Column Group ».

Title (de la colonne)
Questions fréquentes sur l'agent IA de recrutement
  1. 1
    Question : Qu'est-ce qu'un agent IA de recrutement ?
    Réponse (texte enrichi) :

    Un agent IA de recrutement est un assistant basé sur l'intelligence artificielle qui prend en charge les tâches répétitives du recrutement à partir d'une simple demande, écrite ou orale.

    Avec Flatchr, l'agent rédige vos offres d'emploi, retrouve des profils dans votre CVthèque, ajoute des CV, prépare vos comptes rendus d'entretien et reformule vos messages aux candidats. Vous gardez toujours la décision finale.

  2. 2
    Question : Comment fonctionne l'agent IA de recrutement Flatchr ?
    Réponse (texte enrichi) :

    Vous échangez avec l'agent comme avec un collègue, sur WhatsApp ou depuis Flatchr, par message écrit ou par note vocale. Il comprend votre demande et l'exécute dans votre ATS.

    Tout ce qu'il produit (offres, fiches candidats, comptes rendus, messages) est enregistré dans Flatchr : les RH et les managers travaillent sur les mêmes informations.

  3. 3
    Question : Faut-il installer une application pour utiliser l'agent ?
    Réponse (texte enrichi) :

    Non. Vos managers utilisent l'application qu'ils ont déjà dans leur poche : il suffit d'écrire ou d'envoyer une note vocale à l'agent. Aucun nouveau logiciel à apprendre, aucune formation nécessaire.

  4. 4
    Question : L'agent IA prend-il des décisions à la place du manager ?
    Réponse (texte enrichi) :

    Non. L'agent prépare, propose et vous fait gagner du temps, mais c'est toujours vous qui validez : une offre avant sa mise en ligne, un message avant son envoi, un candidat avant de le retenir.

  5. 5
    Question : L'agent IA de recrutement est-il conforme au RGPD ?
    Réponse (texte enrichi) :

    Oui. L'agent fonctionne au sein de l'ATS Flatchr, conforme au RGPD dès sa conception : gestion des consentements des candidats, archivage automatique des candidatures et outil d'anonymisation.

    L'aide à la sélection repose uniquement sur des critères liés au poste, et un accord de traitement des données (DPA) vous est fourni sur demande.

  6. 6
    Question : Où sont hébergées les données traitées par l'agent IA ?
    Réponse (texte enrichi) :

    Les données personnelles de vos candidats restent en France, dans des centres de données certifiés ISO 27001 et conformes SOC 2, comme pour le reste de l'ATS Flatchr.

    Flatchr ne partage jamais les informations personnelles de vos candidats : vous gardez la maîtrise de vos données de recrutement.

    ⚠️ À valider : Confirmer que les traitements IA de l'agent (modèle utilisé, transcription des notes vocales) sont eux aussi hébergés en France, et préciser le cas des échanges WhatsApp, qui transitent par Meta. Attention : /security dit « en France », /faq dit « en Europe ».

  7. 7
    Question : Comment l'agent protège-t-il les données sensibles ?
    Réponse (texte enrichi) :

    Chaque utilisateur n'accède qu'aux informations dont il a besoin selon son rôle : un manager voit ses recrutements, les RH gardent une vision d'ensemble.

    L'agent n'utilise aucune donnée sensible (santé, origine, opinions, vie privée) pour vous aider à sélectionner les candidats : seuls les critères liés au poste comptent.

    ⚠️ À valider : Confirmer que l'agent ignore bien les données sensibles (santé, origine, opinions…) dans l'aide à la sélection.

  8. 8
    Question : Les données de mes candidats servent-elles à entraîner l'IA ?
    Réponse (texte enrichi) :

    Non. Les CV, notes vocales et échanges traités par l'agent servent uniquement à vos recrutements. Ils ne sont pas utilisés pour entraîner des modèles d'intelligence artificielle.

    ⚠️ À valider : Réponse à confirmer impérativement avec Damien : dépend du fournisseur du modèle IA et du contrat signé avec lui.

  9. 9
    Question : Comment l'agent limite-t-il les biais dans la sélection des candidats ?
    Réponse (texte enrichi) :

    L'agent compare chaque candidature aux seuls critères de votre offre, sans tenir compte d'informations sans rapport avec le poste. Aucun candidat n'est écarté automatiquement : toutes les candidatures restent consultables et la décision reste humaine.

    ⚠️ À valider : Confirmer la formulation « sans tenir compte d'informations sans rapport avec le poste ».

  10. 10
    Question : Que se passe-t-il quand j'envoie la photo d'un CV ?
    Réponse (texte enrichi) :

    L'agent lit le CV, crée la fiche du candidat dans votre CVthèque et peut la rattacher à l'offre en cours. Le CV papier remis en boutique ou en agence ne se perd plus.

  11. 11
    Question : L'agent est-il adapté aux réseaux de franchise et aux entreprises multisites ?
    Réponse (texte enrichi) :

    Oui. Chaque manager de point de vente peut recruter en autonomie avec ses propres demandes, tandis que l'agent s'appuie sur vos modèles d'offres communs. Le siège ou les RH gardent une vision consolidée de tous les recrutements dans Flatchr.

  12. 12
    Question : Quand l'agent IA de recrutement sera-t-il disponible ?
    Réponse (texte enrichi) :

    L'agent IA de recrutement Flatchr est disponible à partir du 1er janvier. Vous pouvez dès maintenant activer votre accès gratuit pour faire partie des premiers utilisateurs.
